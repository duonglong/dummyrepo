# Form View Field Organizer

Lets administrators and consultants organize any form: hide fields by user group,
group fields into collapsible sections, show or hide fields by other values,
reorder fields, and keep a layout per company with a shared default.
Layouts are applied on top of the original views and never change them, so
uninstalling the module restores every form.

Hiding a field is display only; it is not a security measure.

Dependency: `web`.
